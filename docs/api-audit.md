# Public API audit

English | [简体中文](api-audit.zh-CN.md)

This audit maps the current Go public surface to the pinned Playa oracle in
[`compat/upstream.toml`](../compat/upstream.toml). It is the detailed symbol
ledger behind the concise naming rules in README.

## Classification

| Go package / symbols | Classification | Direction |
|---|---|---|
| `playa.Open`, `OpenBytes`, `Document`, `Page` | Playa model plus Go adaptation | Retain; `Close` and returned errors replace Python context-manager/exception control flow. |
| `playa.PageList`, `DeviceSpace`, `Point`, `Rect`, `ObjRef`, `ContentStream` | Playa root facade re-exports | Expose the repeatable lazy page sequence, coordinate-space value, PDF geometry tuples, indirect-reference value, and content-stream value without reintroducing mutable document ownership. |

| `parser.Lexer.Data` | Go lexical-parser source-buffer accessor | Return a defensive copy by default; the document inline-image path uses the explicitly named `DataBorrowed` view so the hot path avoids an extra allocation without exposing mutable storage through the ordinary accessor. |
| `playa.Resolve` and `playa.ResolveAll` | Playa `resolve`/`resolve_all` | Use an explicit Go reference lookup callback; `Resolve` follows a bounded reference chain with an optional default and cycle guard, while `ResolveAll` retains recursive copy semantics. |

The root package is a compact facade only. It must not re-export every internal
content type as a convenience shortcut; domain types belong in their named
packages.

Contexts, required callbacks, and pointer receivers must be non-nil. Passing nil
is a programmer error, with no library sentinel or fallback result promised.
Concurrent page workers retain their existing callback-panic recovery; a nil
callback therefore fails when invoked through that recovery path. Nil functional
page-concurrency options remain optional and are ignored. Optional model fields
and documented optional resolver/filter arguments retain their own nil semantics.
